# Schaufenster

Vollbild-Webapp fuer einen Bildschirm im Schaufenster einer Buchhandlung.

Der Screen stellt neue Buecher, Bestseller, aktuelle Schaufenster-Themen und kommende Events animiert dar. Die erste Version nutzt lokale Beispieldaten direkt in `src/App.jsx`.

## Entwicklung

```bash
npm install
npm run dev
```

Die lokale App laeuft standardmaessig auf `http://127.0.0.1:5173/`.

## Produktion

```bash
npm run build
```

Der gebaute Output landet in `dist/`.
